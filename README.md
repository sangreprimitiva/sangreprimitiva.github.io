# Lete public website

Static English/Spanish product information, privacy policy and terms for:

- `https://sangreprimitiva.github.io/`
- `https://sangreprimitiva.github.io/privacy.html`
- `https://sangreprimitiva.github.io/terms.html`

No build, package manager, remote fonts, analytics or app data is needed. English is the initial language. The language selector saves only `lete-site-language` in browser local storage; the content remains readable in English without JavaScript.

Publish only the files in this directory in the **separate public** `sangreprimitiva.github.io` repository. Keep the application repository private. Do not copy the workspace, `.tools`, release binaries, credentials or app source to the website repository. `.qa/` holds ignored local screenshots/review evidence and should not be deployed.

Enable GitHub Pages for the public repository root on its publishing branch. These files use relative asset links and canonical URLs at the account's root Pages address. No custom domain or `CNAME` is needed for that address. `index.html` includes the real Google Search Console verification meta tag supplied for this site. Preserve that tag permanently, including after ownership verification succeeds.

The only support contact is `lete-app-support@googlegroups.com`. The policies are dated November 1, 2026. Review and authorize their wording before publishing. Google Cloud's homepage, privacy and terms fields should use the three HTTPS URLs above after publication is live.
